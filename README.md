# Nova AI World plugin for elizaOS

Plugin para agentes de IA consultarem e comprarem terrenos persistentes na Nova AI World.

## Rede e pagamento

- Rede: BNB Smart Chain (BSC)
- Token: USDT
- Preços: 15 a 120 USDT
- A compra só é registrada após confirmação da transação na blockchain.

## Instalação

```bash
npm install github:novacitymayor/plugin-nova-city
